# Vue 3 + Vite

--> Midproject-2
ToDo App es una aplicación web desarrollada con Vue.js y Supabase que permite a los usuarios gestionar tareas mediante un tablero Kanban. La aplicación ofrece funcionalidades como autenticación de usuarios, creación, edición y eliminación de tareas, y una interfaz intuitiva para organizar el flujo de trabajo.

CARACTERÍSITCAS

- Autenticación de usuarios utilizando Supabase.
- Gestión de tareas con estados: Pendientes, En Progreso y Completadas.
- Interfaz de usuario responsive.
- Acceso seguro y personalizado para cada usuario. - Visualización clara del progreso de las tareas.

USO

- Registro e Inicio de Sesión: Los usuarios pueden registrarse con su correo electrónico y contraseña. Una vez autenticados, acceden a su tablero personal de tareas.
- Gestión de Tareas:
  Agrega nuevas tareas utilizando el formulario disponible.
  Cambia el estado de las tareas entre Pendientes, En Progreso y Completadas.
  Elimina tareas que ya no sean necesarias.

-Interfaz Intuitiva: La aplicación presenta una interfaz clara y organizada, facilitando la gestión de tareas diarias.

TECNOLOGÍAS UTILIZADAS

- Vue.js: Framework progresivo para construir interfaces de usuario.
- Supabase: Plataforma de backend como servicio.
- Pinia: Sistema de gestión de estado para Vue.js.
- Vite: Herramienta de desarrollo frontend rápida y moderna.

CONCLUSIÓN
Un proceso entretenido y muy didáctico enfocado al aprendizaje de las herramientas más básicas del FRONT-END.
